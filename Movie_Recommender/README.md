# movie_recomender_app
# 🎬 Movie ML Lab

Interactive Streamlit dashboard for exploring movie recommendation ML models.

## 🚀 Features

- **Content-Based Filtering** - Genre and tag similarity recommendations
- **Collaborative Filtering** - User behavior pattern analysis
- **Model Comparison** - Compare 5 ML algorithms side-by-side
- **Data Explorer** - Browse 85K+ movies with advanced filters
- **Interactive Dashboard** - Real-time visualizations and metrics

## 📊 Dataset

- **Source:** MovieLens 25M
- **Movies:** 85,555 titles
- **Ratings:** 33 million
- **Features:** 175 engineered features
- **Time span:** 1995-2019
